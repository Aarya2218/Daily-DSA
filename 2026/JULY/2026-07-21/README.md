# Largest Element

**Date:** 2026-07-22

## Problem
Find the largest number in an array.

## My First Thought
I wanted to sort the array first.

## Better Approach
Keep track of the current largest value while scanning once.

## Time Complexity
O(n)

## Space Complexity
O(1)

## What I Learned
Sorting was unnecessary because I only needed one value, not the entire array in order.
